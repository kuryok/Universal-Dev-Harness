2. **Transporte `/preview-ipc/preview.sock` (anti-TOCTOU + `SO_PEERCRED`/netns) + Mini-ponte reversa Python stdlib (`runtime/preview_bridge.py`) + Gerenciador e Proxy de Preview (`udh/preview.py`):**
   - **Separação estrita de confiança (`ADR-021`/`B3.4`):**
     - **Descritor do artefato (`/artifact/udh_app.json`, conteúdo não confiável validado fail-closed pelo Core):** declara **exclusivamente** o encaixe operacional do app (`schema_version: 1`, `app_type: "web"`, `entrypoint` `.py` relativo dentro de `/artifact` sem `..`/symlinks, `ready_path` iniciado por `/`, e `docs_files` opcional de caminhos relativos regulares dentro de `/artifact`). Qualquer campo `smoke_checks` ou veredito embutido em `/artifact/udh_app.json` é **ignorado** pelo Core.
     - **Contrato oficial de `smoke_checks` (domínio confiável do Core/spec/`TrustStore`, fora de `/artifact`):** fornecido pelo Core/spec ou descritor selado na `TrustStore` (nunca vindo do artefato), exigindo `len(smoke_checks) >= 1` (fail-closed se vazio), com passos HTTP declarativos (`method`, `path`, `body`/`headers` opcionais, `expected_status`, `expected_substring` opcional, `after_restart: bool` opcional).
   - **Mini-ponte reversa (`runtime/preview_bridge.py`, 100% Python stdlib):**
     - Executada pelo Core dentro do contêiner `artifact` como `python3 -I -B /opt/udh/preview_bridge.py --socket /preview-ipc/preview.sock --artifact /artifact --data /data --entrypoint <entrypoint> --internal-port <porta>`.
     - Valida que `--entrypoint` resolve estritamente como arquivo regular dentro de `/artifact` sem symlinks.
     - Inicia o app web em **processo-filho separado** com `start_new_session=True` (`python3 -I -B /artifact/<entrypoint>`, `shell=False`, `cwd=/data`, `HOST=127.0.0.1`, `PORT=<porta>`, `UDH_DATA_DIR=/data`, `HOME=/data`, `TMPDIR=/data`, `UDH_PREVIEW_MODE=demo|smoke`, `PYTHONDONTWRITEBYTECODE=1`, `PYTHONNOUSERSITE=1`) dentro do namespace `--network=none` (evitando `EROFS` em `/tmp` sob `--read-only`).
     - Aguarda prontidão em `127.0.0.1:<porta>`, cria o Unix Domain Socket `/preview-ipc/preview.sock` (`chmod 0o600`) e encaminha requisições HTTP/1.1 (`Connection: close`, limites rígidos de headers/body e timeouts anti-slowloris) entre `/preview-ipc/preview.sock` e `127.0.0.1:<porta>`, sem abrir qualquer porta TCP no host (`B3.6(d)` / família ADR-020).
     - Ao receber `SIGTERM`/`SIGINT`, encerra o grupo do processo-filho via `os.killpg` e remove o socket.
   - **Conexão UDS segura no Core (anti-TOCTOU + prova de namespace de rede + limite `sun_path` `<= 100` bytes):**
     - O diretório `ipc_dir` (`0700`) é alocado seguindo o padrão de `udh/gateway.py:_choose_ipc_dir()` (`XDG_RUNTIME_DIR` ou `/tmp`, independente de `TMPDIR`, validando `len(sock_path.encode('utf-8')) <= 100` para nunca estourar o limite de 108 bytes de `AF_UNIX`), separado e não sobreposto ao `data_dir` (`0700`).
     - Para conectar sem TOCTOU de symlink (bloqueando SSRF contra `podman.sock` ou `gateway.sock` do mesmo UID):
       1. Abrir `dirfd = os.open(ipc_dir, os.O_RDONLY | os.O_DIRECTORY | os.O_NOFOLLOW)` e `dir_stat = os.fstat(dirfd)`;
       2. Abrir `sock_fd = os.open('preview.sock', os.O_PATH | os.O_NOFOLLOW, dir_fd=dirfd)` e validar via `os.fstat(sock_fd)` que `S_ISSOCK`, `st_uid == os.getuid()` e `st_dev == dir_stat.st_dev`;
       3. Conectar ao socket via `/proc/self/fd/{sock_fd}`;
       4. Antes de enviar qualquer byte HTTP, validar `SO_PEERCRED` (`(peer_pid, peer_uid, peer_gid)`): exigir `peer_uid == os.getuid()` **e** `os.readlink(f'/proc/{peer_pid}/ns/net') != os.readlink('/proc/self/ns/net')` (provando que o par está no namespace isolado `--network=none` do contêiner, jamais no namespace do host).
   - **Proxy autenticado e isolamento de origem (`udh/preview.py`, `B3.6(a)-(e)`):**
     - Cada preview ativo recebe `preview_id` aleatório (`^[0-9a-f]{24}$`, 96 bits), hostname exclusivo `p-<preview_id>.localhost:<porta>`, volume descartável `/data` (`0700`, rotulado `"dados de demonstração"`, `B3.6(e)`), TTL de inatividade/vida útil (`<= 600s`) e garantia de remoção do contêiner + diretórios temporários no `stop()` e no shutdown.
     - **Autenticação de preview desacoplada da UI (`B3.6(a),(c)`):**
       - Iniciar preview (`POST /api/runs/<id>/preview/start`, autenticado com `X-UDH-Token` em `127.0.0.1:<porta>`) retorna um `grant` one-time (TTL curto, uso único) na URL `http://p-<preview_id>.localhost:<porta>/_udh_preview_auth?grant=<grant>`.
       - A rota reservada do Core `/_udh_preview_auth` (nunca encaminhada ao contêiner, sempre com `Cache-Control: no-store` e `Referrer-Policy: no-referrer`) valida e consome o `grant` uma única vez (reuso/inválido → `403`), emite cookie **host-only** (sem atributo `Domain`), `HttpOnly`, `SameSite=Lax`, `Path=/`, nome `_udh_preview_session=<token_exclusivo_do_preview>` e redireciona `303` para `/`.
       - **Compatibilidade honesta `SameSite=Lax` vs `<iframe>` cross-site (`B3.6(c)`):** o fluxo padrão abre em **aba separada** (`target="_blank" rel="noopener noreferrer"`, `frame-ancestors 'none'`, 100% compatível com `SameSite=Lax` sem enfraquecer CSRF). Quando o usuário solicita o modo iframe complementar opcional, `frame-ancestors` libera exclusivamente `http://127.0.0.1:<porta>` e, diante do bloqueio de cookie `SameSite=Lax` em iframes cross-site HTTP nos navegadores modernos, a UI solicita um **novo grant one-time** via `POST /api/previews/<pid>/grant` (autenticado com `X-UDH-Token`) para abrir o fallback em aba separada sem reuso de grant e sem jamais rebaixar o cookie para `SameSite=None`.
       - Toda requisição subsequente a `p-<preview_id>.localhost:<porta>/*` exige `_udh_preview_session` válido (`hmac.compare_digest`) vinculado exatamente àquele `preview_id`; requisições mutantes (`POST`/`PUT`/`PATCH`/`DELETE`) no host de preview também validam `Origin == http://p-<preview_id>.localhost:<porta>` e `Sec-Fetch-Site == same-origin` quando presentes.
       - O proxy **nunca** aceita nem encaminha `X-UDH-Token` (nem `Authorization`) ao app do preview; qualquer presença de `X-UDH-Token` (ou do valor do token da UI em cabeçalhos) no host de preview é recusada com `403` (`B1.7(d)`). Ao remover `_udh_preview_session` do cabeçalho `Cookie:` na ida para o app, preserva demais cookies próprios do app.
     - **CSP restritiva padrão e endurecimento contra resposta hostil (`B3.6(b)`, `ADR-021`):**
       - Tratar toda resposta vinda do UDS como 100% hostil: parser HTTP/1.1 estrito no Core com limites de status/headers/body e timeout; remover cabeçalhos hop-by-hop (`Transfer-Encoding`, `Connection`, `Keep-Alive`, `Upgrade`, `Proxy-*`, `TE`, `Trailer`), re-enquadrar com `Content-Length` + `Connection: close`;
       - Sobrescrever/injetar obrigatoriamente:
         - `Content-Security-Policy: default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self' data:; font-src 'self'; connect-src 'self'; object-src 'none'; base-uri 'none'; form-action 'self'; frame-ancestors 'none'` (ou `frame-ancestors http://127.0.0.1:<porta>` exclusivamente quando o preview tiver modo iframe complementar habilitado); zero fontes, scripts, estilos ou conexões de terceiros;
         - `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, `Permissions-Policy: camera=(), microphone=(), geolocation=(), payment=(), usb=()`, `Cache-Control: no-store`;
         - remover cabeçalhos `Refresh` e `Set-Cookie2`;
         - sanitizar múltiplos `Set-Cookie` do app: rejeitar/remover qualquer atributo `Domain=` e bloquear sobrescrita (case-insensitive) de `_udh_preview_session`;
         - bloquear redirecionamentos `3xx` com `Location` apontando para outra origem, URL protocol-relative (`//`, `/\`), esquema perigoso (`javascript:`, `data:`), caracteres de controle/espaço ou `127.0.0.1:<porta>` (`502 preview_redirect_blocked`).

     - **Validação estrita em TODA requisição (`B1.7(a)`):**

## 5. Suposições explícitas

1. **Resolução `*.localhost` no host Debian:** `/etc/nsswitch.conf` neste host não ativa `myhostname`, portanto a resolução de subdomínios `*.localhost` ocorre nativamente em navegadores compatíveis com RFC 6761 (como Firefox/Chromium), enquanto a suíte HTTP determinística em Python conecta em `127.0.0.1:<porta>` enviando `Host: p-<id>.localhost:<porta>` explicitamente.
2. **Operação 100% offline e zero credenciais reais:** o build da imagem `artifact-only` reutiliza a camada Alpine já presente no storage local do Podman (`--pull=never --network=none`) e Python 3 do host, sem baixar pacotes nem abrir rede externa. Caso o ambiente impeça build/execução offline em T1, pararemos e consultaremos o usuário (Regra #6).
3. **Sem mudança de esquema SQLite (`user_version=4`):** todas as evidências (`ARTIFACT_PROMOTION`, `AT_RESULT`, `SMOKE_RESULT`) e transições (`PENDING`/`IN_PROGRESS`/`BLOCKED`/`DONE`) já existem no esquema v4; `list_runs` e `count_runs_by_state` são consultas somente leitura compatíveis.
4. **Honestidade de liberação:** concluir o Change 4 valida `B3.1`/`B3.4`/`B3.6`/`B1.7` em Linux x86_64 rootless offline, mas **não** declara MVP liberável completo, nem `DOC-01/02`, nem validação WSL2 (`B1.1b`), que permanecem pendentes conforme `STATE.md` e `openspec/project.md`.
