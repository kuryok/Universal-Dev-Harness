- [ ] **T2 — Contrato `udh_app.json`, cliente UDS anti-TOCTOU e gerenciador/proxy de preview isolado (`B3.6`)** (`udh/preview.py`)
  - Implementar validação fail-closed do descritor `/artifact/udh_app.json` restrita ao encaixe operacional (`schema_version: 1`, `app_type == 'web'`, `entrypoint` `.py` relativo dentro de `/artifact` sem symlinks/traversal, `ready_path`, `docs_files`), ignorando qualquer campo `smoke_checks` oriundo do artefato.
